GIS Area Rates

GIS Integration with TRM

1. GIS Interface

1.1 Summary

Some property tax rates are geographic in nature, with the applicability or rate dependent on the location of the property. Halifax’s GIS system is the system of record for the boundaries where these location-based rates apply. This development will allow TRM to query GIS via a REST api. For a given AAN or PID, GIS will return a list of all applicable location dependent rates. The query can be called in bulk, or for a single AAN.

1.2 Technical Details

Twice a year, after area rates have been updated in GIS, bulk update Rate applicability in TRM:

  1. Maintain table ZDC_TRM_PTGIS to set the tax year to be updated.
  2. Execute Z_TRM_PARCEL_GIS_AREA_RATES in background
  3. Review GIS updates in the fiori apps GIS update monitor or GIS update report, to observe which AANs have not been updated (via the GIS update date).
  4. Execute Z_TRM_PARCEL_GIS_AREA_RATES in background for those AAN, this time by PID.
  5. If any AANs are still not updated, review these with the GIS team.
  6. For Mobile Home, ensure that each mobile home is assigned to a parcel update of type MOBH (tx code RELMRC)
